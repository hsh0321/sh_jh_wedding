# A Winter Letter · 성현과 지현

`index.html`을 브라우저에서 열면 작동하는 독립 HTML/CSS/JS 청첩장입니다.

- 레퍼런스: https://fromlilt.kr/preview/template/LILT_001
- 파우더 블루, 빈티지 프레임, 종이 질감의 방향을 참고했습니다. 프레임·리본·봉투는 새로 그린 SVG/CSS이며 원본 사이트의 이미지/소스/로고를 복사하지 않았습니다.
- 사진과 배경음악은 기존 프로젝트의 최적화된 파일을 포함합니다.
- 봉투 오프닝, 음악, 사진 확대/스와이프, 달력, 일정 저장, 카운트다운, 지도 연결, 계좌/주소 복사 제공.
- 모션 최소화 설정을 존중하며 음악은 사용자 버튼 조작 후에만 재생됩니다.
- 폰트는 Google Fonts를 사용하며 오프라인에서는 시스템 서체로 대체됩니다.
- 파일 열기는 PC 확인용입니다. 모바일 링크 공유는 호스팅이 필요합니다. 방명록/참석 응답 등 서버 저장 기능은 포함하지 않았습니다.

`node server.cjs`는 PC 내 검수용 서버입니다. `node build.cjs`는 기존 studio 템플릿을 바탕으로 HTML을 재생성하는 개발용 도구이며 배포 시 필요하지 않습니다.
