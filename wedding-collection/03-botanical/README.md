# Evergreen — 함께 자라는 마음

가든 · 꽃 피는 오프닝

index.html을 브라우저에서 직접 열면 실행됩니다. HTML, CSS, JS와 assets만 사용하는 독립 프로젝트입니다. 이 폴더만 다른 곳으로 복사해도 동작합니다.

내용 수정: index.html / 디자인: style.css의 .theme-botanical / 날짜, 사진 순서, 버튼 기능: script.js

오프닝은 ‘초대장 열기’ 또는 ‘건너뛰기’로 진행합니다. 하단에서 다시 볼 수 있습니다. JS 오류 시에도 8초 후 자동으로 사라집니다. 동작 줄이기 설정을 지원합니다. 음악은 버튼을 누를 때만 재생됩니다.

공유는 공개 배포 주소에서 이용하세요. 파일 직접 열기에서는 링크 공유 대신 안내를 표시합니다. 공개 배포 시 og:image를 공개 주소의 절대 URL로 변경하세요. Google Fonts에 연결되지 않으면 시스템 글꼴로 표시됩니다.
