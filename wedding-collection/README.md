# Wedding Design Collection

index.html을 열면 10개 디자인을 비교하고 선택할 수 있습니다. 각 번호 폴더는 assets를 포함하는 독립 HTML/CSS/JS 프로젝트입니다. 서버나 패키지 설치가 필요 없습니다.

- 01-velvet-letter: Velvet Letter — 클래식 · 봉투 오프닝
- 02-blue-hour: Blue Hour — 코발트 · 셔터 오프닝
- 03-botanical: Evergreen — 가든 · 꽃 피는 오프닝
- 04-cinema: The Premiere — 시네마 · 커튼 오프닝
- 05-peach-pop: Peach Club — 피치 · 팝업 오프닝
- 06-hanji: 연, 緣 — 한지 · 문이 열리는 오프닝
- 07-modern-muse: Modern Muse — 모던 · 타이포 오프닝
- 08-starry-night: Written in Stars — 미드나이트 · 별빛 오프닝
- 09-memory-book: Our Little Book — 스크랩북 · 폴라로이드 오프닝
- 10-lilac-dream: Lilac Dream — 라벤더 · 베일 오프닝

개발용 원본: shared.css, shared.js, build.cjs. node build.cjs를 실행하면 각 프로젝트가 재생성되므로 개별 폴더에서 수정한 내용은 덮어씁니다. 원본 wedding-editorial은 변경하지 않습니다.
