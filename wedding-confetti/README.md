# With Love · Confetti

참고: https://fromlilt.kr/preview/template/LILT_008

샘플을 직접 확인하고 하트 사진, 파우더/체리 색상, 스크롤에 반응해 어두워지는 표지와 흩어지는 도트, 중앙에서 좌우로 펼쳐지는 사진, 항목별 스크롤 등장, 스크롤에 따라 반대 방향으로 이동하는 인터루드 타이포그래피와 종이 질감을 HTML/CSS/JS로 재구현했습니다. 샘플의 유료 그래픽·사진·소스 파일을 복사하지 않고 기존 두 분 사진과 새 코드로 구성했습니다.

색상 선택, 음악, 사진 슬라이더/확대/스와이프, 달력 저장, 카운트다운, 지도 연결, 계좌 전환/복사, 링크 공유가 작동합니다. 참석 여부 회신, 서버 저장·방명록·문자 자동전송은 포함하지 않습니다. 샘플의 가상 교통·주차·식사 안내와 전화번호는 사용하지 않았습니다. 실제 영상 주소가 없어 영상 삽입은 제외했고, 지도는 임베드 대신 네이버·카카오 지도 링크로 연결합니다.

`index.html`을 직접 열거나 기존 모음 사이트에서 체험할 수 있습니다. `node build.cjs`는 HTML과 공통 유틸리티를 재생성합니다.
