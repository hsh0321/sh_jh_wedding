# The Beginning — 성현과 지현의 첫 장

원본과 독립적으로 실행되는 두 번째 모바일 청첩장 프로젝트입니다. 아이보리·딥 올리브 컬러와 에디토리얼 타이포그래피로 디자인했습니다.

## 실행

이 폴더에서 `npm start`를 실행한 뒤 http://127.0.0.1:4173 을 엽니다. 외부 패키지를 설치할 필요가 없습니다. `index.html`을 직접 열 수도 있습니다.

## 구성

- 초대글, 가족 소개, 웨딩 사진 9장과 전체 화면 갤러리
- 한국 시간 기준 카운트다운, 달력 및 ICS 일정 다운로드
- 안내용 약도, 기존 네이버·카카오 지도 링크, 주소 복사
- 예식 안내, 계좌 복사, 공유, 선택 재생 배경음악
- 모바일 하단 바로가기, 키보드 사진 탐색, 스와이프, 모션 감소 설정 지원

내용은 `index.html`, 색상과 레이아웃은 `style.css`, 갤러리 순서와 날짜·기능은 `script.js`에서 수정합니다. `assets`에는 원본에서 복사한 사진과 음악이 들어 있어 상위 프로젝트 없이 옮길 수 있습니다.

## 배포 메모

정적 호스팅에 이 폴더를 업로드할 수 있습니다 (`server.cjs`와 `package.json`은 서버 미리보기용). 공개 주소가 정해지면 `og:image`를 해당 주소의 `/assets/main.jpg` 절대 URL로 변경하세요. 로컬 미리보기 주소는 다른 사람에게 공유해도 접속할 수 없습니다. Google Fonts에 연결되지 않으면 시스템 글꼴로 표시됩니다. 안내 약도는 실제 축척이 아니며 길찾기는 연결된 지도 서비스를 사용합니다. 원본 안내 이미지에는 구체적인 교통·주차 내용이 없어 임의로 추가하지 않았습니다.
