# Wedding Studio — Collection 02

index.html을 직접 열면 실제 화면 캡처로 10개 디자인을 선택할 수 있습니다. 각 번호 폴더는 사진·음악을 포함한 독립 HTML/CSS/JS 프로젝트입니다.

사진과 예식 정보는 사용자의 기존 청첩장에서 가져왔습니다. 오프닝, 갤러리, 한국 시간 기준 카운트다운, 일정 다운로드, 지도 링크, 계좌 복사, 음악 및 공유 기능이 포함되어 있습니다. 외부 패키지 설치 없이 동작하며 Google Fonts에 연결되지 않을 때는 시스템 글꼴로 표시됩니다.

## 파일
- 01–10 폴더: 각각 독립 청첩장
- screenshots: 오프닝, 첫 화면, 전체 스크롤 JPG
- REFERENCES.md: 실제 확인한 참고 자료 및 인스타그램 접근 제한
- build.cjs, style.css, script.js: 개발용 공통 원본. node build.cjs는 각 프로젝트 파일을 덮어써 재생성합니다.

## 확인
10개 모바일 화면에서 가로 넘침·깨진 이미지 없이 사진 9장이 표시되는 것을 확인했습니다. 대표 디자인에서 오프닝, 건너뛰기, 다시 보기, 스크롤 해제, 갤러리 이동, 계좌 펼치기를 확인했습니다. 일정 파일 다운로드의 실제 저장은 브라우저 다운로드 권한 때문에 이번 검수에 포함하지 않았습니다.

공개 배포 시 og:image를 공개 절대 URL로 바꾸세요. 공유 버튼은 로컬 주소를 외부에 공유하지 않도록 공개 호스팅 주소에서만 동작합니다.
